## NBR 6120:2019 — Cargas variáveis (Tabela 10)

| Uso | Carga uniforme (kN/m²) |
|---|---|
| Dormitórios, salas, copas, cozinhas (residencial) | 1,5 |
| Corredores de uso común (residencial) | 3,0 |
| Salão de festas / salão de jogos / academia | 3,0 |
| Garagens de veículos de passageiros | 3,0 |
| Comercial / escritórios (salas de uso geral) | 3,0 |
| Balcões, sacadas, varandas (residencial) | 2,5 |
| Forros accesibles solo mantenimiento | 0,1 |
| Paredes divisórias (posición no definida) | 0,5–1,0 (variable) |

**Peso específico:** concreto armado **25 kN/m³** · revestimiento de piso 5 cm ≈ **1,0 kN/m²**
**Alvenaria de vedação** (bloque cerámico 9–14 cm c/ revestimiento): 1,1–1,9 kN/m²

## Valores adoptados para el edificio (CDE, Paraguay — NBR como norma base)

| Nivel | g (kN/m²) | q NBR (kN/m²) | q ASCE (kN/m²) |
|---|---|---|---|
| S1–S3 cocheras | losa 6,0 + acabados 0,5 = **6,5** | 3,0 | 1,92 |
| PB comercial | losa 5,75 + acabados 1,5 = **7,25** | 3,0 | 4,79 |
| P01–P18 residencial | losa 4,75 + acabados 1,0 + tabiquería 1,5 = **7,25** | 1,5 (corredores 3,0) | 1,92 |
| AZ azotea | losa 7,5 + impermeabilización 2,0 = **9,5** | 1,0 | 0,96–1,92 |

**Cargas puntuales azotea:** piscina agua = 10 kN/m³ × profundidad media 1,5 m ≈ **15 kN/m²**;
tanques potable/PCI = 45 m³ × 10 / 49 m² ≈ **9,2 kN/m²** (agua) + estructura ≈ 10 kN/m².
