# 05.02_Familias

Familias de Revit (.rfa) de arquitectura, estructura e instalaciones usadas en el proyecto (mobiliario, puertas, ventanas, elementos estructurales, artefactos sanitarios).

Guardar con nombre y parámetros tipificados, ej. Familia_Columna_50x50.rfa. Evitar familias duplicadas o genéricas no utilizadas.
