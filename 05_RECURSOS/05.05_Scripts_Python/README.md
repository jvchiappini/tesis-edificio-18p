# 05.05 — Scripts Python de Ingeniería & Algoritmos

Módulos Python de cálculo, análisis dinámico, geometría y optimización algorítmica del proyecto de tesis:

1. **`01_Geometria_Terreno/`:** Verificación y cálculo de coordenadas UTM WGS84 (P1-P4 7.618,49 m²), polígono edificable inscripto y retiros.
2. **`02_Ingenieria_Viento/`:** Motor de cálculo multinormativo comparativo (**NP 196:1991**, **NBR 6123:2023**, **ASCE 7-22**, **EN 1991-1-4**), cortante basal y momento de vuelco.
3. **`03_Calculo_Estructural/`:** Análisis y dimensionamiento de losas nervadas alivianadas, bajada de cargas tributarias, pilares H°A° y pantallas.
4. **`04_Optimizacion_Algoritmica/`:** Algoritmos genéticos multiobjetivo (NSGA-II con librería `DEAP`) para optimización de recintos.
5. **`05_Exportacion_BIM_IFC/`:** Scripts de exportación automatizada de geometría estructural a modelos IFC4 y Revit 2024.
