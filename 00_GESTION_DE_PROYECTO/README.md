# 00_GESTION_DE_PROYECTO — Gestión BIM (ISO 19650)

Centro de gestión BIM y planificación estratégica del proyecto de tesis. Estructura simplificada en 3 subcarpetas principales:

1. [**`00.01_BEP_Plan_de_Ejecucion_BIM`**](00.01_BEP_Plan_de_Ejecucion_BIM/): Plan de Ejecución BIM (BEP), matriz de responsabilidades y entregables por LOD.
2. [**`00.02_Normativa_y_Referencias`**](00.02_Normativa_y_Referencias/): Normas técnicas aplicables (NP 196, NBR 6123, ASCE 7-22, NBR 6118, ACI 318-19, ISO 19650) y artículos científicos de referencia.
3. [**`00.03_Estandares_del_Proyecto`**](00.03_Estandares_del_Proyecto/): Estándares obligatorios de nomenclatura de archivos (`NOMENCLATURA.md`), modelado BIM (`ESTANDARES_BIM_Y_MODELADO.md`) y redacción académica (`ESTANDARES_DOCUMENTACION_Y_TESIS.md`).

- [**`ROADMAP_TESIS_300_PAGINAS.md`**](ROADMAP_TESIS_300_PAGINAS.md): Roadmap metodológico ejecutivo y plan de redacción para la tesis de grado (~200–300 páginas).
